"What a waste of what" 
A grid of white squares explores the question of a grid, and the futility of creating/interpreting. 
I was trolled myself in the search for perfectly white squares, to hide the borders of the images, getting rid of the visual effect of a grid (borders).
Instead, I found only images of drywall and screens with subtle values. 
My intention was to create a grid that you could not tell was a grid, but nonetheless I failed and have resigned to a somewhat subtle grid. 

This ironic/genuine failure relationship was exacerbated by the disruption of my pattern when I changed my screen size after I copied my code into GitHub from p5. 
The perfectly square composition I had created in p5 is stretched into a discontinuous rectangle.
